When Trackers Fail: VLM-Guided Verification and Recovery for Robust Video Object Segmentation

Memory-based trackers like SAM 3 fail silently: one wrong prediction enters the memory and is propagated forever. Dual-Agent adds a verifier that notices and a corrector that recovers, with the tracker left frozen.

The problem: propagation has no way to notice it is wrong

SAM-style trackers predict each frame from the current image and a memory of their own past predictions. That recursion is their strength and their weakness: once a wrong mask is written into memory, every later frame reads from it. Better memory design delays this; nothing in the loop detects or repairs it. The result is identity switches to look-alikes, missed reappearances, and false positives during occlusion.

Rows: ground truth, SAM 3, Dual-Agent. Once SAM 3 loses the target it does not come back on its own; Dual-Agent recovers it and tracking continues normally.

The idea: verify, then recover

Keep the propagator frozen and add a thin control layer with two specialists. A verification agent decides whether the track is still the target. A correction agent, called only on a detected failure, decides where the target is. A committed correction re-prompts SAM 3, so propagation resumes from a clean state instead of a corrupted one.

One triggered frame, in four steps

Trigger

Three cheap signals from SAM 3 decide when to look: polling during an occlusion, a delayed check after a reappearance, and an early warning when the tracker's own confidence turns unstable, which happens during identity swaps before any hard disappearance.

Verify

A zero-shot VLM (Qwen3-VL-8B-Thinking) sees two trusted exemplars, four context frames with the tracker's own possibly wrong boxes, and the query frame. It first locates the target itself, then judges whether the tracker's box is on it. Three votes are pooled.

Correct

Only on a detected failure, a lighter fine-tuned VLM (Qwen3-VL-4B-Instruct) relocalizes the target or declares it absent, with up to three verifier-checked rounds.

Commit

The correction overwrites SAM 3's memory only if it differs substantially from the current hypothesis. SAM 3 is re-prompted and propagation resumes from a clean state. One wrong commit pollutes many frames; one right reset recovers a long segment, so triggering is sparse and commitment is conservative.

The corrector is trained on failures mined from SAM 3's own runs on SA-V (79k samples), with identity-switch perturbations that reproduce the ambiguities that make propagators fail. On held-out queries it recovers +0.59 IoU where SAM 3 lost the target and slightly hurts where SAM 3 was already right, which is exactly why the verifier decides when to call it.

Results

With the propagator frozen, Dual-Agent improves it on both VOS benchmarks, most where identity has to be re-established. The gain comes from 88 committed corrections over 160 SecVOS videos, with the verifier reaching only 4.8% of frames and 40 of 52 checkable commits improving on SAM 3. The same agents, unchanged, help other propagators and single-object trackers.

Limitations

  • Only as good as the verifier. In ambiguous scenes it can miss a failure or override a correct track; 9 of 52 checkable commits on SecVOS did so.
  • Not real-time. About 72 s per SecVOS video on one H100 versus 12 s for SAM 3; FP8 verification and sparser polling bring it to 48 s at 76.4 J&F.
  • Protocol caveats. LaSOT-ext is a size-selected composite; on VOT-LT recall rises while precision drops.
