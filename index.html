Abstract

Segmentation-based trackers built on foundation models such as SAM propagate masks through a memory of past predictions. The memory is what makes them strong, and what makes them brittle: under occlusion, reappearance and look-alike distractors, errors enter the memory and compound, and the tracker keeps producing confident masks of the wrong object or of nothing at all. Prior work improves the propagator; it still assumes its own predictions can be trusted.

We propose a failure-aware tracking framework that keeps SAM 3 frozen and adds explicit reasoning and selective recovery on top. A vision-language verification agent reasons over spatio-temporal context to decide whether the current track is still the target, catching identity switches, missed recoveries and distractor-induced drift. Only when it flags a failure is a correction agent activated to relocalize the target, and a commit gate decides whether the correction may overwrite the tracker's memory. Targeted training perturbations teach the corrector the exact ambiguities that make propagators fail. The result turns tracking from a purely propagation-based process into a self-correcting system: with SAM 3 untouched, it improves LVOS-v2 by +1.2 and SeCVOS by +2.7 J&F, intervening on fewer than 5% of frames.

How it works

SAM 3 keeps doing what it does best: memory-based mask propagation. A sparse trigger gate watches cheap tracker signals (occlusion, reappearance, confidence variance) and only occasionally wakes the verification agent, a vision-language model that looks at trusted exemplars of the target together with the tracker's own recent, possibly corrupted, context and decides whether the track is still the right object. When it says no, the fine-tuned correction agent relocalizes the target or declares it absent, and a commit gate decides whether that correction may overwrite SAM 3's memory. A committed correction re-prompts SAM 3, so propagation resumes from a clean state instead of a drifted one.

Verifying and correcting are different jobs

Deciding whether the track is wrong and deciding where the target is are split between two agents, so each can be a precision-oriented specialist instead of one model doing both.

Tracker-aware reasoning

The verifier sees both trusted exemplars and the tracker's own recent predictions, so it reasons about the state the tracker is actually in rather than about a clean oracle trajectory.

State-safe intervention

A wrong correction rewrites future memory, so interventions are rare by design: sparse triggers decide when to look, a commit gate decides whether a correction is trusted enough to overwrite the tracker state.

Failure-oriented supervision

The corrector is trained on perturbations that mimic identity switches and distractor-induced drift, the exact ambiguities that make SAM-style propagators fail.

Scene cuts and reappearance (SeCVOS)

SeCVOS is built around shot changes. Each cut resets the scene, and SAM 3's memory of the previous shot stops matching anything: its IoU falls to zero and stays there. Long videos (LVOS-v2)

LVOS-v2 videos run for minutes with the target leaving and re-entering the view. Once SAM 3 misses a reappearance, it rarely recovers on its own. Each clip starts with both trackers on the object, then jumps to the reappearance where they diverge; everywhere else the dual agent is SAM 3.

Results

With SAM 3 kept entirely frozen, the dual agent improves it on both benchmarks and reaches the strongest numbers in each table. On SeCVOS the gain grows with scene complexity and is largest on multi-scene-change videos, exactly where identity has to be re-established rather than refined.
