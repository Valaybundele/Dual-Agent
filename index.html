When Trackers Fail: VLM-Guided Verification and Recovery for Robust Video Object Segmentation

1University of Tübingen, Germany

Abstract

Recent segmentation-based trackers built on foundation models such as Segment Anything Model (SAM) achieve strong performance through memory-based mask propagation. Despite their strong generalization ability, these methods remain brittle under occlusion, reappearance, and distractor scenarios, where errors accumulate and lead to identity drift. Existing approaches improve robustness through better memory design and temporal modeling, yet they implicitly assume that propagated predictions remain reliable over time, lacking a mechanism to identify and correct failures.

We propose a failure-aware tracking framework that augments segmentation-based propagation with explicit reasoning and selective recovery. Our key idea is to decouple tracking into two complementary processes: verifying prediction reliability and recovering the target when failures occur. We introduce a dual-agent architecture consisting of a vision-language verification agent and a correction agent. The verification agent reasons over spatio-temporal context to assess whether current predictions remain consistent with the target object, detecting identity switches, missed recoveries, and distractor-induced failures. When unreliable predictions are identified, the correction agent is selectively activated to recover the target using temporal cues. Targeted training perturbations that simulate identity switches and distractor-induced drift further improve robustness under ambiguous scenarios. By explicitly modeling failure detection and recovery inside the tracking loop, our framework turns tracking from a purely propagation-based process into a self-correcting system. On LVOS-v2 and SeCVOS, it improves SAM 3 by +1.2 and +2.7 J&F without modifying the propagator.

Method Overview

SAM 3 stays frozen and keeps doing what it does best: memory-based mask propagation. On top of it we add a thin control layer. A sparse trigger gate watches cheap tracker signals (occlusion, reappearance, confidence variance) and only occasionally wakes a verification agent, a vision-language model that looks at trusted exemplars of the target together with the tracker's own recent, possibly corrupted, context and decides whether the current track is still the right object. When it says no, a fine-tuned correction agent re-localizes the target (or declares it absent), and a commit gate decides whether that correction may overwrite SAM 3's memory. A committed correction re-prompts SAM 3, so propagation resumes from a clean state instead of a drifted one.

Key Ideas

Verify and correct are different jobs

Deciding whether the track is wrong and deciding where the target is are separated into two agents, so each can be a precision-oriented specialist instead of one model doing both.

Tracker-aware reasoning

The verifier sees both trusted exemplars and the tracker's own recent predictions, so it reasons about the state the tracker is actually in rather than about a clean oracle trajectory.

State-safe intervention

A wrong correction rewrites future memory, so interventions are rare by design: sparse triggers decide when to look, and a commit gate decides whether a correction is trusted enough to overwrite the tracker state.

Failure-oriented supervision

The corrector is trained on perturbations that mimic identity switches and distractor-induced drift, the exact ambiguities that make SAM-style propagators fail.

Quantitative Results

With SAM 3 kept entirely frozen, the dual agent improves it on both long-video benchmarks and reaches the strongest numbers in each table. On LVOS-v2 it also gives the best unseen-object scores. On SeCVOS, built around scene cuts and reappearance, the gain grows with scene complexity and is largest on multi-scene-change videos, exactly where identity has to be re-established rather than refined.

Qualitative Results

Each video shows the same LVOS-v2 sequence tracked by SAM 3 (left, red) and by the dual agent (right, blue), with the ground-truth box in green. The two differ only inside the short windows where the verifier fires and a correction is committed; everywhere else the dual agent is SAM 3.

Reappearance after a long absence. The rider disappears behind the pillars of a parking garage. SAM 3 stays silent after he returns; the dual agent re-acquires him on the first verifier call that sees him again.

Missed recovery. Same garage, a second person. SAM 3 misses him for several seconds after he re-enters the frame; the dual agent recovers him and hands the clean state back to the tracker.
